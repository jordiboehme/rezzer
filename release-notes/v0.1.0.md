# Greetings, programs

The first release: Rezzer reads your files and hands what they know to your AI agent as Markdown.

## New & Noteworthy

- **Files are more than their text.** An agent that reads a file with a quick script gets only the words. The tables break, the formulas are gone and the comments are lost. Rezzer keeps the structure, the metadata and the logic behind the content. These formats are in 0.1.0:
  - Plain text in any encoding. Rezzer finds the encoding and the language. The output is always UTF-8.
  - Markdown: the structure and the frontmatter of the file stay. Rezzer adds an outline and the links, wikilinks included.
  - CSV and TSV: the delimiter, the header, titles and several tables in one file. Rezzer also finds the type of each column, the columns that look like keys and the columns that are the sum of others.
  - Spreadsheets (XLSX, XLSM, XLSB and ODS): the values and where they come from. You get the formulas with the cells they read, the inputs and the results, names, number formats, validation rules and comments. Rezzer finds the tables, headers and titles inside each sheet and can write each row as a record. XLSB gives values, formulas and names only.
  - PDF: the text in reading order with its tables and the outline. Annotations stay at their passage, with author and date. Form fields come with their calculations. Scripts, signatures and revisions are listed too. Forms that are only printed text and lines (a pay slip, an insurance notice) keep each label next to its value. Barcodes and QR codes are read. When the file has no title or date of its own, Rezzer finds them on the first page. A date counts only when a label like "Date" marks it. Rezzer doesn't guess.
- **No silent gaps.** What Rezzer can't read is listed in the output: what, where and why. Pictures it can't interpret are marked in the text. With `-o` they are written to files, so an agent that can see pictures can look at them.
- **Your agent should not have to write a script for each file.** One binary does the reading. On the command line: `rezzer read report.pdf`. Add `-o out/` to write the Markdown and its pictures to a folder. For agents: `rezzer mcp` runs a local MCP server with the tools `rez`, `inspect` and `formats`. In Claude Code: `claude mcp add rezzer -- rezzer mcp`. Rezzer runs on your machine and sends nothing anywhere.
- **Knowledge you read once should stay.** The output is ready for [Crystalline](https://github.com/jordiboehme/crystalline) 0.29.1 or later: the frontmatter follows the Open Knowledge Format (OKF) and works with Crystalline's engram frontmatter. Tags come from the file itself. Each date says how sure it is. With `-o` a large document becomes a main document with linked parts, each small enough for one tool answer.
- **Rezzer runs where your files are.** There are builds for six platforms: Linux on amd64 and arm64 (static, runs on any distribution), macOS on Apple silicon and Intel (signed and notarized) and Windows on amd64 and arm64. The Windows binaries are not signed yet, so SmartScreen may ask once before the first run. On macOS and Linux: `brew install jordiboehme/tap/rezzer`.
- **You should know what you run.** `SHA256SUMS` holds the checksum of every archive and SBOM. It is signed with cosign in GitHub Actions, without a key: the signature names the workflow that made it. Each archive also has a build attestation (`gh attestation verify`), an SBOM and `THIRD-PARTY-NOTICES.txt`. The README shows the commands.

Breaking changes: None.
