# CAD corpus manifest (spike 2026-10-19)

Public test files with a redistributable license for the CAD and engineering spike. Four groups,
each in its own folder: `mcad/` (FreeCAD, STEP, IGES, Fusion, native MCAD), `drawing/` (DXF, DWG),
`mesh/` (3MF, STL, OBJ, glTF, G-code), `bim-eda/` (IFC, KiCad, Gerber/Excellon, OpenSCAD).
File paths in the tables are relative to the group folder. Each group section below is the
group's own manifest (also kept as `<group>/MANIFEST-part.md`).

All files are untrusted data. No script or build file lives in this folder: synthetic files were
made by generator scripts in `spike/cad-test/<group>/` (or `gen/`), and files over 50 MB were
generated into the scratchpad and deleted after the run.

License flags: files from the FreeCAD repository are LGPL-2.1 data, files from the PrusaSlicer,
BambuStudio and OrcaSlicer repositories are AGPL-3.0 data, the MinnowBoard MAX Gerbers are
CC-BY-SA-3.0, and a few FreeCAD files are CC-BY-SA-4.0. All are redistributable as test data and
are flagged in their rows. Excluded on purpose: the NIST MTC assembly (CRADA project, no license
text, vendor fastener models), 3DBenchy-derived files and CC BY-NC-SA models, IfcOpenShell test
files (GPL/LGPL) and LibreDWG test data (GPL repository, unclear provenance).

Totals: about 390 files, 168 MB (mcad 34 MB, drawing 36 MB, mesh 55 MB, bim-eda 43 MB).
