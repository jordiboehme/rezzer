# Formats

One page per format: what Rezzer gets out of it, which crates it builds on, how it shows up in the output and what it can't do yet.

Rezzer is in the design phase. Nothing is implemented yet. These pages describe what is planned.

| Page | Formats | Status |
|---|---|---|
| [PDF](pdf.md) | PDF | first release |
| [XLSX](xlsx.md) | XLSX, XLSM, XLSB | first release |
| [XLS](xls.md) | XLS (Excel 97-2003) | first release |
| [ODS](ods.md) | ODS | first release |
| [DOCX](docx.md) | DOCX | first release |
| [DOC](doc.md) | DOC (Word 97-2003) | first release |
| [ODT](odt.md) | ODT | first release |
| [RTF](rtf.md) | RTF | first release |
| [PPTX](pptx.md) | PPTX | first release |
| [PPT](ppt.md) | PPT (PowerPoint 97-2003) | first release |
| [ODP](odp.md) | ODP | first release |
| [EPUB](epub.md) | EPUB 2 and 3 | first release |
| [HTML](html.md) | HTML | first release |
| [PostScript](postscript.md) | PostScript, EPS | first release (document facts), text later |
| [CSV](csv.md) | CSV, TSV | first release |
| [Plain text](text.md) | Plain text in any encoding | first release |
| [Markdown](markdown.md) | Markdown | first release |
| [CAD](cad.md) | DXF, 3MF, FreeCAD, STEP, IGES, IFC, STL, OBJ, glTF, KiCad, Gerber, G-code, OpenSCAD, native CAD formats | first release; the exact list of CAD formats depends on tests that are still running |

| [Mathcad](mathcad.md) | Mathcad Prime, Mathcad 12-15, SMath | later release |
