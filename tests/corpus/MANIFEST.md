# Test corpus

Public files with licenses that allow redistribution. Each file is data: it is only read, never executed. "Derived" means the file was changed from a public source (transcoded, cut); it keeps the license of its source. License texts and attributions are in `LICENSES.md`. Large files that are not in the repo are listed in `remote.tsv` and fetched with `scripts/fetch-corpus.sh`.

Every file in `web-text/` has a `<file>.facts.json` next to it and golden snapshots in `snapshots/`. The files in `office/` (spreadsheets, with `office/malformed/` for regression files that broke other readers) are downloaded unchanged from the pinned commit of their source; they get facts and snapshots when the spreadsheet readers land.

## PDF files (`pdf/`)

The PDF files are downloaded unchanged from the pinned commit of their source (the IRS form and the scanned letter from the page named in the row). Each SHA-256 was checked against the spike manifest (`docs/spike-2026-10-19/MANIFEST-pdf.md`). Two larger files are not in the repo and are listed in `remote.tsv` only: `pdf/nist-sp800-53r5.pdf` (NIST SP 800-53 Rev. 5, US government work, public domain) and `pdf/arxiv-2408.09869-docling-report.pdf` (arXiv 2408.09869v5, CC-BY-4.0).

`pdf/qpdf-user-password.pdf` is encrypted (AES-256, revision 6) with the **user password `view`** and the owner password `master`. Both passwords are documented in the qpdf test suite (`qpdf/qtest/encryption.test` at the same commit, case 25 uses `--password=view`). The other two encrypted files use an empty user password.
